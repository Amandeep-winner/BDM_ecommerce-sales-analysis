## 📋 Project Overview

This is a **Business Data Management Capstone Project** completed as part of the **IITM BS Degree Program**. The project leverages modern data analytics tools and techniques to provide actionable insights into e-commerce sales performance and inventory management.

### 🎯 Key Objectives

- 📈 Analyze e-commerce sales trends and patterns
- 📦 Optimize inventory efficiency and management
- 💡 Generate actionable business insights
- 📊 Create comprehensive data visualizations
- 🔍 Support data-driven decision making

## 🚀 Getting Started

### Prerequisites

```bash
- Python 3.8 or higher
- pip (Python package installer)
- Jupyter Notebook
```

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/Amandeep-winner/BDM_ecommerce-sales-analysis.git
cd BDM_ecommerce-sales-analysis
```

2. **Create a virtual environment**
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

3. **Install required packages**
```bash
pip install -r requirements.txt
```

4. **Launch Jupyter Notebook**
```bash
jupyter notebook
```
